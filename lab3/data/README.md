# Учебный корпус «ЛираТех»

В приложенных материалах доступны требования к корпусу и факты из контрольных вопросов. `corpus.json` — учебная реконструкция по этому описанию. 36 карточек образуют 35 уникальных ID, 6 разделов и 12 подразделов. Тексты, даты и ID дополнительных карточек синтетические. Они позволяют проверить дерево, версии, фильтры и обработку видимости.

В `control_questions.json` вопросы К01–К08 взяты из методички. Сценарии К09–К15 составлены для проверки реализации. К16 проверяет пример внедрения инструкции, упомянутый в методичке. Точная формулировка К16 и его карточка синтетические.

`cloud_ok` разрешает передавать безопасные отрывки модели в облаке, `local_only` требует локального маршрута. Секция в S-04 с `allow_rag: false` доступна через `get_doc` для чтения оригинала. Поиск не индексирует её и не отдаёт в отрывках.
